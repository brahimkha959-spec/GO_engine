📋 خطوات التصدير من Blender:

  1. حدد المجسم المطلوب في Blender
  2. File → Export → Wavefront (.obj)
  3. فعّل "Apply Modifiers" و "Triangulate Faces"
  4. اضبط Scale = 1.0 ثم احفظ
  5. اسحب الملف إلى هذه النافذة
